# Лабораторная №2 — RAG на SciFact

Проверяем, помогает ли поиск научных аннотаций модели определять истинность утверждений. Это эксперимент, а не медицинская система и не обучение новой модели.

## Что происходит

1. Берём 5183 аннотации SciFact и превращаем каждую в вектор из 384 чисел кодировщиком BGE-small.
2. Так же кодируем утверждение. Скалярное произведение нормированных векторов показывает близость; выбираем первые k документов.
3. Собираем найденные документы по порядку в промпт до 2048 токенов, сохраняя исходные номера предложений.
4. Qwen3-4B отвечает JSON: SUPPORT — подтверждено, CONTRADICT — опровергнуто, NOINFO — недостаточно сведений. Для первых двух меток нужны документ и предложения.
5. Сравниваем ответ с разметкой. Отдельно проверяем: нашли ли документ, дошло ли обоснование до модели, правильно ли она ответила.

LLM-only получает только утверждение. RAG получает найденные тексты. Oracle получает готовое эталонное обоснование: это диагностическая проверка чтения, не обычная система поиска.

Всего 420 оцениваемых ответов. Прогревы из train хранятся отдельно. Dev — 90 утверждений, по 30 каждого класса. Holdout — 210 утверждений, для лабораторной №3: модель их здесь не получает.

Технический журнал: первоначальная CUDA-сборка завершилась аварийно после 91 оценочного запроса (ошибка доступа к памяти в `ggml_cuda_mul_mat_q`). Этот незавершённый запуск `runs/20261106_182557` сохранён отдельно на исходном компьютере, без удаления неудачных ответов; в архив для сдачи аварийные прогоны не включены. Vulkan также завершился аварийно после 15 запросов (runs/20261106_183549). Итоговые 420 запросов выполнены полностью на CPU; в отчёте используется только этот единый запуск. Ошибки внутри итогового прогона учитываются как неверные ответы.

## Запуск в PowerShell

Открыть папку проекта:

```powershell
cd D:\project\python\lab2
```

Посмотреть готовый отчёт без повторного расчёта:

```powershell
Start-Process .\report.pdf
```

Проверить код:

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_rag
```

Открыть MLflow:

```powershell
.\.venv\Scripts\mlflow.exe ui --backend-store-uri sqlite:///mlflow.db --host 127.0.0.1 --port 5001
```

В браузере открыть http://127.0.0.1:5001, эксперимент `lr2`, запуск с окончанием `experiment2`. Ось X выбрать **Step**: шаги 1, 3, 5 — это k, а не эпохи обучения. Остановить сервер — Ctrl+C.

Только три метрики в MLflow:

| График | Что показывает |
|---|---|
| `accuracy` | Доля правильных меток среди всех 90; выше — лучше |
| `correct_citation` | Доля из 60 утверждений с эталоном, где верны метка и ссылка на полное обоснование |
| `evidence_in_prompt` | Доля из тех же 60, где нужное обоснование целиком дошло до модели |

Значения MLflow 0–1: 0.8 означает 80%. Три оформленных PNG находятся в артефактах `analysis`: сравнение режимов, поиск/доставка обоснования, качество RAG при разных k. Больше документов не гарантирует лучший ответ: они могут не поместиться или отвлечь модель.

Полный повтор экспериментов (измерения и кодировщик работают на CPU, 8 потоков):

```powershell
.\.venv\Scripts\python.exe experiment.py
.\.venv\Scripts\python.exe analyze.py
.\.venv\Scripts\python.exe make_report.py
```

Оборванный запуск можно продолжить, указав его реальную папку:

```powershell
.\.venv\Scripts\python.exe experiment.py --resume runs/ИМЯ_ПАПКИ
```

Уже записанные ответы, включая ошибки, не перезапрашиваются. Не меняйте конфигурацию или код между началом и продолжением измерений.

Готовые отчёт, графики, матрицу и JSONL можно смотреть без установки модели. Виртуальное окружение не копируется: создаётся заново. Для новых вызовов рядом нужна папка `lab1` с сервером и моделью из первой лабораторной:

```text
  lab1/models/Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf

```

Установить Python 3.12 и выполнить в папке lab2:

```powershell

.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для восстановления MLflow по готовым JSONL достаточно `python analyze.py` из созданного окружения: новых вызовов модели нет. Локальную базу MLflow переносить между компьютерами не требуется, поскольку пути к артефактам могут отличаться.

Для новых измерений используется CPU-сервер из соседней lab1. GPU не требуется. Готовые результаты можно смотреть без модели.

При полной пересборке данных/индекса:


Архив SciFact уже включён. Для загрузки кодировщика нужен интернет. Ревизия использованного кодировщика закреплена в паспорте индекса. Существующие измерения и индекс не перезаписывайте, если хотите сохранить именно сданный результат.

## Короткий словарь

- **k** — сколько первых документов берём из выдачи. Реально переданных может быть меньше.
- **Токен** — единица текста, которую выделяет токенизатор; это может быть часть слова, слово или знак. Бюджет считается токенизатором Qwen после шаблона диалога.
- **Embedding / вектор** — набор чисел, представляющий текст для поиска; здесь 384 числа.
- **Score** — близость векторов; не вероятность истинности утверждения.
- **Rationale / обоснование** — размеченный набор предложений, достаточный для решения.
- **Accuracy** — правильные метки / все проверяемые утверждения. Ошибки вызова или разбора входят в знаменатель.
- **Recall класса** — доля правильно распознанных утверждений именно этого класса.
- **Hit@k** — найден хотя бы один нужный документ; усредняем по 60 утверждениям с эталоном.
- **Recall@k** — найденная доля нужных документов; затем среднее по этим 60.
- **MRR@k** — среднее 1/место первого нужного документа, либо 0, если его нет в top-k.
- **Температура 0** — выбор наиболее вероятного продолжения; это не seed и не качество ответа.
- **Seed 42** — начальное состояние генератора случайных чисел; одинаковое число не гарантирует совпадение на другом оборудовании.
- **max_tokens 128** — максимум длины ответа, отдельно от 2048 входных токенов.

Код подготовлен с помощью Codex; корректность проверяется тестами, сохранёнными запросами, ответами и контрольными суммами. Дополнительные необязательные эксперименты из задания не выполнялись.
